# IDEC diploma project — SQL Server high availability (2021)

This folder contains the final documentation for my 2021 systems and network administration diploma at IDEC, Renens. The document is dated 8 June 2021.

## Documented scope

The report covers requirements, alternatives and design decisions, an infrastructure diagram, Active Directory changes, a failover cluster, SQL Server availability groups, read-only routing, access roles, backup arrangements and maintenance.

The report describes a three-server SQL Server solution and its implementation in the project scenario. The academic context should be retained when interpreting the responsibilities and results described in the document.
