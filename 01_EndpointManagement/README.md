# Endpoint Management

This directory contains projects and scripts related to endpoint administration, Microsoft Intune, Windows management, Microsoft Graph, security, and troubleshooting.

The content published here represents selected technical examples rather than a complete production toolkit. Each project should be reviewed and tested before use in a production environment.

## Projects

- [Listing des programmes installés](https://github.com/alaindespont/AD-PUBLIC/tree/main/01_EndpointManagement/Listing%20des%20programmes%20install%C3%A9s) — Windows software inventory script (2021).
- [Test de connectivité de station de travail](https://github.com/alaindespont/AD-PUBLIC/tree/main/01_EndpointManagement/Test%20de%20connectivit%C3%A9%20de%20station%20de%20travail) — Windows network troubleshooting script (2022).
